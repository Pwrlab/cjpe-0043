Refilling Tool v2 (PWRlab, Beijing Forestry University)
=======================================================

No Python installation is needed.

Windows
  1. Unzip the folder (do not run it inside the zip).
  2. Double-click RefillingTool.exe. A black window opens and then your browser
     shows the tool at http://localhost:8501.
  3. If Windows SmartScreen warns: "More info" -> "Run anyway".
  4. Close the black window to quit.

macOS (Apple Silicon)
  1. Unzip the folder.
  2. First time only, open Terminal and run (drag the folder into Terminal to get its path):
       xattr -dr com.apple.quarantine /path/to/RefillingTool
     or right-click RefillingTool -> Open -> Open.
  3. Double-click RefillingTool. The browser opens at http://localhost:8501.
  4. Close the Terminal window to quit.

Data never leave your computer: the page only talks to localhost.
Method: Chinese Journal of Plant Ecology, 2023.0043.
